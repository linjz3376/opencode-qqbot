# 拟人执行端点（AEE）规范

AEE = 运行「被测 persona 真实客户端」的宿主（物理机/虚拟机/真机/浏览器/云真机）+ 一个五操作标准接口的驱动层。一切「需要真人客户端配合」的验收与执行任务，对上层只暴露本规范。

## 一、五操作标准接口

| 操作 | 语义 | 判定要求 |
|---|---|---|
| probe() | 宿主与客户端存活探测 | 返回 {宿主活、客户端进程/页面在、几何信息} |
| address(id) | 寻址到目标会话/页面 | 目标标识（标题/URL/群名）须在取证中可见——禁止假设上下文 |
| input(payload) | 拟人输入（文本/媒体/手势） | 等价真人输入事件；粘贴为下限，逐键为佳；输入后必有回执 |
| capture() | 判定时取证 | 从 persona 视角捕获（截图/DOM 快照）；判定时刻留证 |
| gesture(x) | 控件级动作（点/滑/滚动/对话框） | 动作后必须验证可观察变化，否则该次动作不算完成 |

## 二、三通道纪律（任何 AEE 恒成立）

- 指挥通道：任务发起人↔指挥者，低噪音
- 测试通道：执行者经 AEE 与被测系统交互（测试面纯净，无指挥噪音）
- 观察通道：指挥者↔执行者，纯机器读数（接口/日志/台账），不过 persona 面

## 三、适配器档案（Implementation Profiles）

| 档案 | 宿主形态 | 遥控通道 | 输入原语 | 取证原语 |
|---|---|---|---|---|
| win-native | Windows 桌面客户端（IM/邮件/办公等） | 远程命令通道→交互会话交付层（计划任务链/代理守护） | 键鼠事件/剪贴板 | 窗口级截取（绕合成器陈旧帧）/屏幕截取 |
| web-dom | 浏览器内客户端 | 浏览器自动化驱动 | click/fill/keyboard 真实事件 | DOM 快照+判定时截图 |
| android-adb | Android 真机/模拟器 | adb | `adb shell input` | UI 树导出 + 截屏 |
| macos | macOS 客户端 | 远程命令通道/代理守护 | 键鼠自动化/系统脚本 | 系统截屏 |
| cloud-farm | 云真机平台 | 厂商 API | 厂商输入 API | 厂商截图 API |

**适配器准入清单**（每档上线前逐项实测打勾）：真事件可用/判定时取证可用/对话框可处理/滚动可用/几何归位可用/凭据注入点隔离/单活或几何漂移有对策。缺项=该端点降级声明，不得静默改判。

## 四、可移植纪律

1. **身份锚定**：每阶段开头 address+取证确认目标标识可见；绑定漂移后不复验不输入。
2. **几何纪律**：坐标永远从当前实测取证推导；布局变化全部作废重取；几何先归位再操作。
3. **交互会话交付**：输入事件必须送达 persona 的真实交互会话——遥控通道若落在非交互会话，一切输入静默失效，必须先经交互会话交付层（计划任务链/代理守护/平台 API，按档案选型）。
4. **取证双模**：判读模式（执行者在环读图，能发现错会话/错布局这类模板不可见异常）为默认；陈旧帧/渲染挂起时按档案切换替代取证通道。
5. **证据同时刻**：PASS 也留证；事后补证不升级判定。
6. **密钥隔离**：凭据只经密钥注入点进入驱动进程，不回显、不落盘、不入产物。

## 五、失效模式对照表

| 抽象失效模式 | 表现 | 档案无关处置 |
|---|---|---|
| 输入静默丢失 | 输入事件被非交互会话吞掉 | 交互会话交付层前置（纪律 3） |
| 取证陈旧/空白 | 合成器陈旧帧、消息区不渲染 | 替代取证通道+输入唤活+端点重启规程 |
| 绑定漂移 | 会话被他端切换/选择错位/超时回落 | address 复验+有意切换走显式命令 |
| 客户端只驻托盘 | 重启后无主窗口 | 唤窗规程（二次唤起/几何归位） |
| 凭据外泄风险 | 凭据文件被误传/误入产物 | 注入点单点+只读使用 |

## 六、与指挥/执行架构的接口

- AEE 是执行者伸到真人世界的手：执行者不绑 persona 面，一切 persona 交互经五操作完成。
- 指挥者通过观察通道读执行者结果；capture() 产出即 UI 主证来源。
- 新端点接入 = 实现一个适配器 + 过准入清单 + 在任务书通道表登记可用性与授权，上层架构零改动。
